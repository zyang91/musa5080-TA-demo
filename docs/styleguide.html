Style Guide

Every element the Blueprint theme styles, on one page.

This page exists to exercise the theme in styles/. Toggle light/dark with the switch in the navbar — the same rules serve both, driven by the --bp-* custom properties each palette file defines.

Type scale

Body copy is Inter at 17px with a 1.65 line height. Headings are Fraunces, a variable serif; the SOFT, WONK and opsz axes are set per level, which is why the page title has more character than the section heads. Labels, dates and code use JetBrains Mono.

Third-level heading

Inline code spans sit in a hairline box, and links draw their underline as a background gradient so it can thicken on hover without moving the baseline.

Blockquotes are set as margin notes: italic Fraunces against an orange rule.

Section numbering

The §01, §02 markers to the left of each h2 come from a CSS counter, not from the Markdown. Nothing in a .qmd file has to know its own number, and the table of contents stays clean because the numbers live in a ::before.

Code and output

Code blocks carry a green left rule; printed output gets a recessed strip underneath, so input and output read as two different things.

## Type scale

Body copy is Inter at 17px with a 1.65 line height. Headings are Fraunces, a
variable serif; the `SOFT`, `WONK` and `opsz` axes are set per level, which is
why the page title has more character than the section heads. Labels, dates and
code use JetBrains Mono.

### Third-level heading

Inline `code spans` sit in a hairline box, and [links draw their underline as a
background gradient](https://quarto.org) so it can thicken on hover without
moving the baseline.

> Blockquotes are set as margin notes: italic Fraunces against an orange rule.

## Section numbering

The `§01`, `§02` markers to the left of each `h2` come from a CSS counter, not
from the Markdown. Nothing in a `.qmd` file has to know its own number, and the
table of contents stays clean because the numbers live in a `::before`.
